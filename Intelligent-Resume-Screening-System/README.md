# 🧠 Intelligent Resume Screening System

An AI-based Resume Screening System developed during my **AI Internship**. This project analyzes resume data and predicts suitable job categories using Python, Natural Language Processing (NLP), and AI techniques.

## 🚀 Project Overview

The objective of this project is to automate the resume screening process by analyzing resume text and predicting the most appropriate job category. This helps simplify the initial screening process and demonstrates the practical application of AI in recruitment.

## ✨ Features

- Resume text preprocessing
- Data cleaning
- Resume classification
- Job category prediction
- Data visualization
- Model performance evaluation

## 🛠 Tech Stack

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Natural Language Processing (NLP)
